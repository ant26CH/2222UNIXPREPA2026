Synthèse complète des 9 modules (Cours Stella Roulière) + TP et Évaluations ING2030

Méthodes de connexion et Session CLI / SSH
Les méthodes courantes sont le terminal local (tty), SSH (CLI) et l'interface graphique (GUI). La connexion `root` via GUI ou SSH (par défaut) est interdite.
ssh user@ipConnexion distante sécurisée.
passwdChanger son mot de passe (rien ne s'affiche à la frappe).
ttyAffiche le nom du terminal associé au processus en cours (ex : /dev/pts/4).
whoAffiche les utilisateurs connectés à la VM (nom, terminal, date, IP).
idAffiche l'UID, le GID et les groupes secondaires de l'utilisateur actuel.
lognameAffiche le nom de connexion de l'utilisateur actuel.
exitSe déconnecter (ou `logout`, ou `[Ctrl]+[d]`).
Gestion des processus et Services Éval
historyAffiche l'historique de toutes vos commandes.
systemctl status sshAffiche le statut du service SSH (et permet de trouver son Process ID principal).
ps -ef | grep sshAffiche les processus SSH en cours pour trouver le PID de votre session.
kill [PID]Stoppe un processus via son PID.
journalctl | grep "nom"Recherche les logs systemd concernant un identifiant précis.
Chemins et Navigation
Chemin absolu : part toujours de la racine / (ex: /home/user/doc). Valide partout.
Chemin relatif : part du répertoire courant (ex: ../doc). . = courant, .. = parent.
pwdAffiche le chemin absolu du répertoire actif.
realpath dossierAffiche le chemin absolu (ex: realpath NetworkConfig).
cd /cheminChanger de répertoire.
Création et Suppression
mkdir dir1 dir2Créer plusieurs répertoires d'un coup.
mkdir -p a/b/cCréer une arborescence (crée les parents si besoin).
touch f1 f2Créer des fichiers vides ou modifier l'horodatage.
rm fichierSupprimer un fichier.
rm -r dossierSupprimer un dossier récursivement.
Affichage (ls) et Manipulation (cp, mv)
ls -laListe tout, y compris les fichiers cachés (commençant par .), avec les détails (droits, propriétaire, taille).
cp source destCopier un fichier. Utiliser cp -r pour un répertoire.
mv source destDéplacer ou renommer un fichier/dossier.
file fichierIdentifier le type d'un fichier (ASCII, directory, block special...).

Lien Physique (Hard Link)
Association entre un nom et un inode unique. Partage les mêmes données sur le disque.
ln cible lienCréation (ex: ln f1.txt /tmp/f1_link.txt).
Si le fichier source est supprimé, les données restent accessibles via le lien physique.
Limité au même système de fichiers. Interdit pour les répertoires.
Lien Symbolique (Symlink)
C'est un raccourci pointant vers un chemin. Plus flexible mais plus fragile.
ln -s cible lienCréation (ex: ln -s f2.txt /tmp/f2_link.txt).
Si le fichier source est supprimé, le lien est "cassé" (dangling). Peut pointer vers des répertoires.
ls -liAffiche les informations des fichiers, y compris le numéro d'inode (première colonne) pour vérifier les liens physiques.
Affichage de texte
cat fichierAffiche tout le contenu. cat -n numérote les lignes.
less fichierPagineur avancé (navigation avec flèches, q pour quitter). Pour exécuter une commande dedans (ex: date) : taper !date puis Entrée.
more fichierPagineur basique (Espace = page suiv, Entrée = ligne suiv).
head -n 5 f.txtAffiche les 5 premières lignes.
tail -n 8 f.txtAffiche les 8 dernières lignes (Vu en éval : tail -8 /etc/passwd).
Redirections et Flux
>Redirige et écrase. (ex: echo "texte" > fic.txt).
>>Redirige et ajoute à la fin. (ex: cat >> fic.txt puis Ctrl+D).
2> /dev/nullRedirige les erreurs (stderr) dans le "trou noir".
| (Pipe)Envoie le résultat d'une commande à une autre (ex: cat f.txt | grep mot).
Analyse de texte
wc fichierCompte Lignes, Mots, Caractères.
wc -l *.confCompte uniquement les lignes.
diff f1 f2Compare deux fichiers (< vient de f1, > vient de f2).
tee fichierAffiche le résultat à l'écran ET l'écrit dans un fichier (utiliser -a pour ne pas écraser).
Recherche de fichiers (find & locate)
find recherche en temps réel selon des critères précis.
find / -name "*.conf"Recherche par nom (utiliser -iname pour insensible à la casse).
find . -type dRecherche par type (d=dossier, f=fichier).
find . -mtime -20Modifiés dans les 20 derniers jours.
find . -size +1kTaille supérieure à 1 Ko.
find / -user Adrouin -type dTous les répertoires appartenant à un utilisateur (Vu en éval).
find . -name "*.conf" -exec chmod 644 {} \;Trouve et applique une commande (ici chmod) sur chaque résultat. {} représente le fichier trouvé.
locate "*.conf" : Recherche très rapide basée sur une base de données (mise à jour via sudo updatedb).
Recherche de contenu (grep & rg)
grep cherche un motif à l'intérieur d'un fichier.
cat /etc/passwd | grep AdrouinCherche un utilisateur dans passwd.
grep -n "interface" *.confAffiche le numéro de ligne (-n).
grep -v "interface" f.confAffiche les lignes qui ne contiennent PAS le motif (-v).
grep -c "mot" f.confCompte le nombre d'occurrences (-c).
grep -rE "[0-9]{1,3}\.[0-9]{1,3}..." .Recherche récursive (-r) avec expression régulière étendue (-E) (ex: chercher des IP).
rg motif (ripgrep) : Alternative plus rapide à grep, récursif par défaut, ignore les fichiers binaires.
Archivage (tar) et Compression
L'archivage (tar) regroupe les fichiers. La compression réduit la taille.
ActionCommandeExplication
Archiver seultar cf archive.tar /dossierc=create, f=fichier
Archiver + Gziptar czf archive.tar.gz /dossierz=gzip (.gz) - Très rapide
Archiver + Bzip2tar cjf archive.tar.bz2 /dossierj=bzip2 (.bz2) - Bon ratio
Archiver + XZtar cJf archive.tar.xz /dossierJ=xz (.xz) - Meilleur ratio, plus lent
Extrairetar xf archive.tar -C /destx=extract, -C pour cibler un dossier précis
Excluretar cf arch.tar --exclude=/dossier .Exclut un dossier de l'archive
Si on demande la compression "la plus efficace" : utiliser XZ (tar cJf ou la commande xz -k archive.tar).
Fichiers Utilisateurs & Groupes
/etc/passwd : Infos utilisateurs (user:x:UID:GID:info:home:shell).
/etc/shadow : Mots de passe hashés et politique d'expiration.
/etc/group : Liste des groupes et de leurs membres.
Sudo
Permet d'exécuter des commandes en tant que root. On gère les accès via le fichier /etc/sudoers (à éditer avec sudo visudo).
Exemple pour ne pas demander de MDP : stella ALL=(ALL) NOPASSWD: ALL.
Gestion des Utilisateurs
useradd -m nomCréer un utilisateur (-m crée le répertoire home).
passwd nomDéfinir ou changer le mot de passe.
usermod -aG sudo nomAjouter un utilisateur à un groupe supplémentaire (ici `sudo`).
chage nomModifier la politique d'expiration du mot de passe (interactif).
chage -l nomVérifier les paramètres d'expiration.
userdel -r nomSupprimer un utilisateur et son dossier home.
Gestion des Groupes
groupadd projetCréer un nouveau groupe.
gpasswd -a user projetAjouter un utilisateur au groupe.
groups userVérifier les groupes d'un utilisateur.
Permissions de base (chmod, chown, chgrp)
Droits : Lecture (r = 4), Écriture (w = 2), Exécution (x = 1). Attribués à Propriétaire (u), Groupe (g), Autres (o).
chmod 644 fic.txtProprio lit/écrit (6), le reste lit (4).
chmod 777 fic.txtTous les droits à tout le monde (vu en éval).
chown user:group fic.txtChange le propriétaire et le groupe d'un fichier.
chgrp projet fic.txtChange uniquement le groupe propriétaire.
Umask
Définit les droits retirés par défaut à la création. Fichier de base (666), Dossier de base (777).
umaskAffiche la valeur (ex: 022).
umask 027Modifie le masque. Donne 640 pour fichiers et 750 pour dossiers. (Ajouter à ~/.bashrc pour persistance).
Access Control Lists (ACL)
Pour donner des droits fins sans changer le groupe (apt install acl).
setfacl -m u:stagiaire:r ficDonne le droit de lecture à 'stagiaire'.
getfacl ficAffiche les ACL du fichier.

RAID 5
Tolérance de panne d'1 disque. Données + parité réparties sur min. 3 disques. Outil : mdadm.
mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sd[bcd]
mdadm --detail /dev/md0Vérifier l'état.
Superblock
Contient les métadonnées vitales du système de fichiers.
